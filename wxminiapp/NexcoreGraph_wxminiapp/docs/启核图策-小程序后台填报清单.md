## 4. 服务类目建议

> 类目决定审核口径与资质要求，以后台可选列表为准；建议按"主类目 1 个 + 相近类目 1 个"提交。

| 优先级 | 建议类目 | 理由 |
|---|---|---|
| 首选 | 工具 → 效率 | 产品本质是"家庭资源管理工具" |
| 备选 | 生活服务 → 家政 / 生活服务 | 覆盖"家庭物品与食材管理"场景 |
| 慎选 | 教育 / 医疗健康 | 涉及药品提醒时可能触发资质要求，非必要不选 |

若后台要求说明 AI 能力：口径为"AI 仅用于拍照识别与方案建议，识别结果全部可由用户编辑确认后保存"。

## 5. 同步要准备的合规项（提审前）

| 项 | 内容 |
|---|---|
| 用户隐私保护指引 | 采集：手机号（登录）、照片（识别入库）、麦克风（可选语音）；用途逐项说明 |
| 数据存储口径 | 聊天记录仅存本机；照片仅用于识别、用户可删除 |
| 账号注销入口 | "我的 → 设置 → 注销账号"（工程当前缺失，见整改文档 M-7） |
| AI 内容标识 | 识别结果、AI 方案处显示"AI 生成"角标 |
| 域名白名单 | `request` / `uploadFile` 指向自建后端 HTTPS 域名（需备案） |
| 订阅消息模板 | 临期提醒 / 采购提醒 / 协作邀请（预留 3 个） |

## 6. 填报顺序建议

1. 填 **名称 + 头像 + 介绍** → 保存（截图里这一页）。
2. 选 **服务类目** → 提交类目审核（可能要求资质）。
3. 配 **服务器域名白名单**（后端就绪后立即配）。
4. 配 **订阅消息模板**（3 个）。
5. 最后提交版本审核；审核通过后再发布（预留 2 个工作日缓冲）。

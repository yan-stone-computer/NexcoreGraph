# 启核图策 · 验收方案（跟做版）

> 版本：v1.0｜日期：2026-09-05｜适用：M2.5 AI 增强 + P0 闭环
> 用法：按顺序做，每步完成打勾；任何一步与「预期」不符即记缺陷（截图 + 步骤号）。
> 预置库存基准：鸡蛋 8 个（3 天到期）、鲜牛奶 1 盒（2 天）、番茄 3 个、上海青 2 把、五花肉 500 克。验证码固定 123456。
> 配套：完整文档第 5 篇（验收标准总纲）；本方案是其可执行跟做版。

## 0. 环境准备

- [ ] 0.1 启动 MySQL：运行 `D:\mysql-8.0.46-winx64\mysql-8.0.46-winx64\bin\mysqld.exe --console`（若未注册服务）；验证：同目录 `mysql.exe --no-defaults -h127.0.0.1 -P3307 -uroot -p123456 -e "use tianshu; show tables;"` → 预期列出 users / families / family_members / sync_snapshots / ops_logs 等 6 张表。
- [ ] 0.2 启动后端：`cd backend && node server.js` → 预期输出监听 0.0.0.0:3000。
- [ ] 0.3 浏览器访问 `http://127.0.0.1:3000/api/health` → 预期返回 ok。
- [ ] 0.4 DevEco Studio 打开本项目 → 启动模拟器 → 点 Run（自动签名安装）。App 内后端地址自动匹配 10.0.2.2:3000，无需配置。

## A. 登录（对应验收标准 A1-A3）

- [ ] A1 输入 13800138000 + 错误码 `123455` → 预期：提示验证码错误，不进入。
- [ ] A2 改输 `123456` → 预期：进入首页看板；后端控制台出现 /api/auth/login 请求。

## B. 拍照入库（B1-B4）

- [ ] B1 资源库 → 拍照入库 → 「模拟拍摄」→ 预期：步骤条进入"AI 识别与补缺"，出现识别结果卡（名称/数量/位置/保质期/价格+来源徽标），toast"Agnes 已识别 N 项"。
- [ ] B2 任意改一项数量、给空字段补值 → 预期：均可编辑。
- [ ] B3 「从相册选择」多选 2-6 张 → 预期：逐张识别后 toast"连拍合并完成：N 张 → M 项"，同名物品数量累加。
- [ ] B4 「确认入库」→ 预期：冰箱库出现新物品；设置页操作日志新增 intake 记录。

## C. 库存与搜索（C1-C4）

- [ ] C1 物品数量 + / − → 预期：即时生效。
- [ ] C2 删除物品 → 预期：toast 带撤销，点撤销恢复。
- [ ] C3 顶栏搜索"鸡蛋" → 跨库命中；改搜"鸡蛋放哪了" → 出现 AI 位置回答卡。
- [ ] C4 新建库"零食柜" → 预期：出现在资源库列表。

## D. AI 快路问答（K1-K4）

入口：悬浮 AI 球。

- [ ] D1 发"你好" → 预期：秒回问候语，气泡下来源小字"本地快答 · 0 次模型调用"。
- [ ] D2 发"牛奶还剩多少" → 预期："鲜牛奶还剩 1 盒（冰箱 · 冷藏区上层）"，数字与库存页一致（红线）。
- [ ] D3 发"鸡蛋放哪了" → 预期：位置 + 数量。
- [ ] D4 发"牛奶还能放几天" → 预期：剩余天数 + 知识库建议，来源小字含"知识库（…）"。
- [ ] D5 发"今天天气怎么样" → 预期：走模型兜底（有 typing 后回答），不编造库存数字。

## E. 改库存 / 购物清单（K6-K7，红线重点）

- [ ] E1 发"鸡蛋只剩 5 个" → 预期：出现按钮「应用调整：鸡蛋 → 5」。**先不点**，去库存页看鸡蛋仍是 8（未盲写，红线）。
- [ ] E2 回来点按钮 → 预期：toast 成功、库存页变 5、操作日志新增。
- [ ] E3 发"牛奶喝完了，加进采购清单" → 预期：出现「加入采购清单：牛奶 …」按钮，确认后顶栏购物车出现该项，来源"AI 对话"。
- [ ] E4 再发一次并确认 → 预期：提示"采购清单里已有「…」"（去重）。

## F. 创新菜谱 + 营养（K8/K10）+ 核销

- [ ] F1 发"用快过期的鸡蛋和番茄做点新花样" → 预期：回复带一句介绍 + 一张新方案卡（来源"AI 创新菜谱"、含"营养速览：约 N 千卡/份（估算）"）；消耗清单里全是库存有的食材，没有的进"缺料"。
- [ ] F2 发"帮我做个减脂餐单" → 预期：回答带热量且标注"约"；若偏好已填忌口则不出现忌口食材（配合 H 组）。
- [ ] F3 方案列表勾选执行 F1 的方案 → 预期：库存对应扣减；点撤销 → 库存回滚（F6.3）。

## 判定标准

1. **红线三条任一违反即不通过**：AI 报的数字与库存不符；未点确认库存就变了；同一提问触发超过 2 次模型调用。
2. A/B/C/D/E/F/G/H/I/K 全勾 = M2.5 验收通过（J3 双设备项可选）。
3. 全部通过后在完整文档 1.10 里程碑处登记"M2.5 验收通过 + 日期"。

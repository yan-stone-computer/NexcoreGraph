# 启核图策 NexcoreGraph · 隐私声明与 AI 合规说明

> 版本：v1.0｜日期：2026-09-15｜适用：鸿蒙端（元服务）· Web 端 · 微信小程序端 · 后端服务
> 对应整改要求：M-13 工程化与合规、缺陷 D8「AI 生成内容标识」、F9.11「聊天记录仅本地」

## 一、我们收集什么

| 数据 | 是否采集 | 存储位置 | 用途 |
|---|---|---|---|
| 手机号 | 是（登录时） | 后端 `users` 表 | 账号识别、家庭成员关系（F9.1/F9.2） |
| 家庭与成员角色 | 是 | 后端 `families` / `family_members` | 家庭协作与权限（只读账号禁写 F9.2） |
| 资源库存（库/物品/数量/位置/保质期/价格） | 是（用户主动录入） | 端侧内存 + 后端同步快照 | 库存管理、临期预警、方案规划（F1/F2/F3） |
| 拍照图片 | 仅在用户主动拍照入库时 | 端侧内存（压缩后 ≤1MB 长边 ≤1600）→ 送后端网关识别 | 视觉识别建库（F1.1）；**识别后不留存原图于服务端** |
| 对话记录 | 是（仅本地） | 端侧 Preferences（滚动保留最近 200 条） | 对话上下文；**不上云、不导出、不跨端同步**（D7 口径） |
| AI 偏好档案（人数/忌口/目标） | 是（用户手填） | 端侧 Preferences | 仅用于菜谱/营养类意图（可在设置中关闭注入） |
| AI 用量（路由/模型/耗时） | 是 | 端侧 Preferences + 后端 `ai_usage` 表 | 用量可观测与限流（M-10） |
| 落地价值指标 | 是 | 端侧 Preferences | 临期消耗率/拦截重复购买/盘点耗时（M-11），仅本机统计 |

**不采集**：通讯录、位置轨迹、通话记录、剪贴板内容、相册全量扫描。

## 二、权限用途

| 权限 | 类型 | 用途 | 拒绝后的影响 |
|---|---|---|---|
| `ohos.permission.INTERNET` | system_grant | 登录、云同步、AI 网关调用 | 无法使用云端与 AI 能力（本地快答仍可用） |
| `ohos.permission.MICROPHONE` | user_grant（带 reason/usedScene） | 语音输入（AI 对话的语音提问） | 仅语音入口不可用，文字对话不受影响 |

相机与相册通过系统 Picker（`photoAccessHelper.PhotoViewPicker`）调用，**不申请** `CAMERA` 全量权限，
仅获得用户当次选择的图片的临时读取授权。

## 三、本地优先策略

- 断网可用：库存查看、临期预警、方案生成、AI 本地快答（问候/位置/数量/保质期）**全部离线可用**；
- 聊天记录、偏好档案、AI 用量、价值指标只落本机，同步快照 payload 仅含
  `{libraries, alerts, plans, shopping, daily, logs}` + `baseVersion`，**不含**上述四类本地数据；
- 冲突处理：云端版本落后于本机时返回 409，由用户二选一（覆盖上传 / 拉取云端），**不静默合并、不丢数据**。

## 四、AI 使用说明与内容标识

| 项 | 说明 |
|---|---|
| 模型调用位置 | **全部经自建后端 AI 网关**（`/api/ai/chat`、`/api/ai/vision`、`/api/ai/tts`）；端侧不含任何模型厂商密钥（D6） |
| 模型可见的数据 | 仅端侧按意图装配的证据块（库存摘要 ≤30 条 + 知识库命中行 + 用户填写的偏好），**不含**手机号与家庭其他成员信息 |
| 数值来源 | 数量/位置/日期**一律由端侧代码查询产出**，模型只做措辞（红线 1） |
| 写操作 | AI 产出的库存调整、采购清单均先给预览卡，**用户点击确认后才写入**（红线 2） |
| 调用次数 | 单次提问 ≤2 次模型调用（主模型 + 失败降级），本地快答命中时 0 次 |
| 内容标识 | 拍照识别结果标注「拍照识别（AI 生成）」；AI 创新菜谱方案标注「AI 创新菜谱（AI 生成）」；AI 回复气泡下方显示证据来源与知识库出处 |
| 知识库来源 | 保质期/存放建议来自 `knowledge/*.json`，引用时展示来源机构与链接（如"中国营养保健食品协会"） |
| 语音合成 | 播报文本截断至 120 字；未配置 TTS 服务或设备无语音引擎时静默降级为纯文字 |

**免责声明**：知识库天数为公开科普资料整理的参考值，不构成食品安全或医疗建议；
食材出现异味、变色、发黏等异常时，无论是否到期均不应食用。

## 五、数据安全

- 模型厂商密钥仅存服务端环境变量（`AGNES_API_KEY`），端侧与前端包内**无 `sk-` 明文**，
  由 `tools/check_release.py` 在提交前静态断言；
- 网关按家庭限流（默认 20 次/分钟），所有调用留痕（路由/模型/耗时/tokens）用于审计；
- 生产部署要求 HTTPS（摄像头、Web Push、Service Worker 依赖）；
- 端侧不做数据库直连，所有持久化经统一 REST 后端或本机 Preferences。

## 六、用户权利

- 可在「设置 → 重置演示数据」清空本地数据；清空对话会同步删除本机落盘的聊天记录；
- 可在「设置 → AI 助手偏好」关闭偏好注入（关闭后菜谱/营养回答不再参考偏好）；
- 可移除家庭成员或退出家庭（后端同步删除成员关系）；
- 账号与库存数据删除请联系项目组（校赛阶段使用演示环境）。

# 启核图策 · 通用知识库

> 版本 1.0｜更新：2026-09-05｜维护方式：见「更新流程」

本文件夹是启核图策的**通用知识库**（离线内置版），对应开发文档 F10.4（知识库管理）、F1.6（保质期与存放建议）、F4.1（知识库优先回答）、F3.1（食材规划）与 AI 对话上下文（M2.5 P0-1 证据注入）。

## 文件结构

| 文件 | 内容 | 用途 |
|---|---|---|
| `foods.json` | 46 项常见食材：常温/冷藏/冷冻保存天数、开封后天数、存放建议、低库存阈值建议 | 入库时自动填默认保质期（F1.6）、临期预警（F3.9）、AI 保质期问答 |
| `recipes.json` | 16 道家常菜谱：用料/缺料/耗时/每份估算热量/标签 | 规则版方案生成（F3.1）素材池、AI 创新菜谱参考、营养速览（M2.5 P0-3） |
| `storage-rules.json` | 10 条食品安全通用规则（温度带、生熟分开、剩菜、解冻等） | AI 对话证据、存放建议、预警文案 |
| `sources.md` | 全部权威来源链接 | 来源标注与追溯（F4.3） |

## 字段说明（foods.json）

- `shelf.pantry / fridge / freezer`：常温 / 冷藏（2-6℃）/ 冷冻（-18℃以下）保存天数（天），`null` 不适用。
- `openedDays`：开封/切开后建议食用天数；无则为 `null`。
- `tip`：存放建议一句话。
- `lowAt`：低库存预警建议阈值（按 `unit` 计），`0` = 不启用（对应开发文档 D4 定稿的 `Item.lowAt` 字段）。

## 对接方式

1. **鸿蒙端（现状）**：`entry/src/main/ets/common/Db.ets` 的 `KNOWLEDGE` 为本库的内置子集；后续改为打包 resources/rawfile 读取 `foods.json` / `recipes.json` / `storage-rules.json`。
2. **后端**：`tianshu.knowledge` 表按本 JSON 结构建表导入；`GET /api/knowledge` 下发，端上缓存（F10.4 管理员端发布流程）。
3. **AI 上下文（M2.5）**：`evidenceFor(expiry/cook)` 意图路由时，将命中的 `foods.json` 行（含 src/url）与 `storage-rules.json` 注入模型证据块，保证「知识库优先回答」。

## 更新流程（F10.4）

1. 管理员端编辑 → 版本号 +1 → 发布；
2. 端上拉取后本地缓存，离线可用；
3. 每条数据保留 `src/url`，AI 回答引用时展示来源。

## 免责说明

所有天数为**参考值**（按常见家庭存储条件与公开科普资料整理），不构成食品安全或医疗建议；AI 回答须保留「以实际状态判断」提示（异味/变色/发黏一律不食）。

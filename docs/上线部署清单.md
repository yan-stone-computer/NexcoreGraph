# 启核图策 · 上线部署清单（阿里云 + 华为侧）

> 面向"真正上线"的可执行版本：要买什么、花多少钱、按什么顺序做、代码还要改什么。
> 价格是 2026 年常见档位的量级参考，**下单前以阿里云控制台实时价为准**（常有新用户/学生优惠）。

---

## 0. 先明确"上线"三个层次

| 层次 | 含义 | 需要什么 |
|---|---|---|
| L1 内测可用 | 你和几个人在真机上能用，别人装不了 | 一台云服务器 + 域名（可不备案，用 IP 或香港节点） |
| L2 公网可访问 | 任何人在任何网络都能登录使用 | L1 + **域名备案**（大陆节点强制，免费但要 7–20 天）+ HTTPS 证书 |
| L3 应用市场上架 | 用户在华为应用市场搜到并安装 | L2 + 华为 AGC 应用/元服务 + 软件著作权（部分类目）+ 隐私合规 + 签名发布证书 |

你现在处在 L0（本地后端 + 模拟器）。**目标建议先做 L2，再排 L3**，因为 L3 的审核材料依赖 L2 的线上环境截图。

## 1. 阿里云要买什么（300 元代金券方案）

### 1.1 必买（合计约 ¥120–200/年，券能全覆盖）

| 产品 | 规格建议 | 参考价 | 干什么用 | 备注 |
|---|---|---|---|---|
| **轻量应用服务器**（优先）或 ECS 突发型 | 2 核 2G / 3–5M 带宽 / 40–60G 盘 | 新用户 ¥68–99/年；常规 ¥24–40/月 | 跑 Node 后端 + MySQL + Nginx | **轻量比 ECS 便宜且够用**；2G 够跑「Node + MySQL + Nginx」这套小流量服务 |
| **域名** | `.cn`/`.com` 任选 | ¥25–60/首年 | 后端 API 域名 + 证书 + 备案必需 | 备案要求域名已实名 |
| **SSL 证书** | 免费版 DV 单域名 | ¥0 | HTTPS | 阿里云可申请免费证书（3 个月或 1 年，按控制台为准） |

**省钱建议**：数据库**不要买 RDS**（最便宜也要 ¥30–60/月，300 券撑不了几个月）。在轻量服务器里自建 MySQL 8，开好 innodb 缓冲即可；数据量小到可以忽略。对象存储 OSS、CDN 现阶段**都不用买**（图片走端侧压缩后直接传后端，量很小）。

### 1.2 可选（先不买，需要再上）

| 产品 | 什么时候需要 | 成本量级 |
|---|---|---|
| 阿里云邮件推送 DirectMail | 163 免费 SMTP 有日发信上限、且容易进垃圾箱；用户量起来后必须换 | 按量，约 ¥0.003–0.01/封 |
| 阿里云短信服务 | 想支持手机号验证码（需先申请签名 + 模板，审核 1–2 天） | 约 ¥0.045/条 |
| 对象存储 OSS | 要长期保存用户拍的原始照片时才需要 | ¥0.12/GB/月，几乎可忽略 |
| DDoS/高防、WAF | 正式对外放量后再考虑 | 数百元/月起 |
| 云监控/日志服务 | 排查线上问题用，可用服务器自带日志替代 | 少量免费额度 |

**300 元大致花法**：域名 ¥49 + 轻量 2核2G ¥99/年 + 证书 ¥0 ≈ ¥148，剩下 ¥150 留作续费/邮件推送。

## 2. 上服务器要做的事（半天）

1. 系统选 **Ubuntu 22.04 / Alibaba Cloud Linux 3**，防火墙只放 22 / 80 / 443（**3000 与 3307 绝不对外**）。
2. 装 Node 18+、MySQL 8、Nginx；`ufw`/安全组收口。
3. 拉代码：`git clone` 仓库后只部署 `harmonyosapp/NexcoreGraph_harmonyos/backend`。
4. `backend/.env` 写线上值（**不要提交**）：
   ```
   AGNES_API_KEY=sk-xxx
   DB_HOST=127.0.0.1
   DB_USER=nxg_app           # 不要用 root
   DB_PASSWORD=<强口令>
   MAIL_HOST=smtp.163.com
   MAIL_USER=covabond@163.com
   MAIL_PASS=<163授权码>
   AUTH_SHOW_CODE=0          # 生产必须 0：否则接口会回带验证码
   ```
5. Nginx 反代 `https://api.你的域名 → 127.0.0.1:3000`，证书用刚申请的。
6. 进程守护：`pm2 start server.js --name nxg && pm2 save && pm2 startup`（或写 systemd unit）。
7. 备份：`mysqldump` 每天 3:00 导出到 `/var/backups`，保留 7 天（一条 crontab）。
8. 端侧改后端地址：`entry/src/main/ets/common/Backend.ets` 的候选地址链，把线上域名放第一位，重新打包。

## 3. 代码侧上线前**必须**改的（安全红线）

| 项 | 现状 | 上线前 |
|---|---|---|
| 数据接口鉴权 | `/api/sync/upload`、`/api/sync/download/:familyId`、`/api/logs/:familyId` 只要拿到 `familyId` 就能读写别家数据 | 用登录发的 token 换 `account`，并校验该账号是否属于这个 family；token 存 `sessions` 表而不是内存 Map |
| 登录 token 存储 | 内存 `Map`，重启即失效 | 落库（token + account + 过期时间），或上 JWT |
| 数据库账号 | 代码默认 `root/123456` | 环境变量强口令 + 只授本库权限 |
| 验证码接口 | 有 60s 防重发 | 再加"同 IP 每小时上限"与失败次数封禁，防短信/邮件轰炸 |
| 明文 HTTP | 端侧候选里有 `http://` | 线上只留 `https://`；鸿蒙上架也会查明文流量 |
| 密钥 | 已在服务端环境变量 | 保持；`.env` 永不入库 |
| 日志 | 打印 Key 前缀（可接受） | 不要打印完整 token/验证码；日志轮转 |

## 4. 华为侧（L3 上架）

1. **AGC**（AppGallery Connect）创建项目与应用；本项目模块是**元服务（atomicService）**，按元服务流程走。
2. 用 AGC 生成 **发布证书 + Profile**，替换 `build-profile.json5` 里的 debug 签名；打 release 包。
3. 准备审核材料：应用图标/截图、隐私政策链接（仓库已有 `docs/privacy.md`，需挂到 HTTPS 页面）、权限使用说明（相机/相册要写清用途）。
4. 若涉及"信息服务"，部分类目要**软件著作权证书**（代办 ¥300–800，或自己申请免费但要 1–3 个月）。
5. 元服务卡片（4 张）随包提交，需在 AGC 配置卡片信息。
6. 想用推送（临期提醒）→ AGC Push Kit，需要真机 + 证书，`push_subscription` 表已就绪。

## 5. 建议的执行顺序

| 步骤 | 内容 | 时间 |
|---|---|---|
| 1 | 买域名 + 轻量服务器，装环境，跑通 HTTPS 反向代理 | 0.5 天 |
| 2 | 提交**备案**（越早越好，等 7–20 天） | 当天提交 |
| 3 | 补第 3 节的安全改造（鉴权/落库/限流） | 1–2 天 |
| 4 | 端侧切线上域名、打 release 包、真机自测 | 0.5 天 |
| 5 | 部署 + 备份 + pm2 守护，L2 达成 | 与 3/4 并行 |
| 6 | AGC 建应用、发布证书、上架审核 | 备案通过后 2–3 天 |

## 6. 常见坑

- **大陆服务器不备案不能用 80/443**：先用 IP:端口 内测（L1），别等备案才开始联调。
- 163 免费 SMTP 对"短时间大量发同一域名"限流，测试期够用，上线换 DirectMail。
- 元服务与 App 的上架材料不同，别按 App 的清单准备元服务。
- 云服务器 2G 内存跑 MySQL 建议把 `innodb_buffer_pool_size` 设成 256–512M，否则容易被 OOM Kill。
- 别忘了把本地模拟器地址（`10.0.2.2:3000`）留在候选链最后，方便你继续本地调试。

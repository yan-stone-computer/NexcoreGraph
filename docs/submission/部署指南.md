# 启核图策 NexcoreGraph · 部署指南

> 版本：1.1
> 日期：2026-11-11
> 适用范围：HarmonyOS 端、AI/同步后端、流转中转、模拟器与真机部署

## 1. 部署形态

项目支持三种部署级别：

| 级别 | 使用场景 | 必需组件 |
|---|---|---|
| L0 本地开发 | 模拟器、单机调试 | DevEco Studio、HAP、可选 Node 后端 |
| L1 局域网演示 | 手机/平板与电脑同一 WiFi | HAP、Node 后端 `3000`、流转中转 `3100`、MySQL |
| L2 公网/上架 | 外网用户、应用市场 | L1 + HTTPS、安全加固、域名/备案、AGC 发布配置 |

当前仓库的一键脚本按 **L1 局域网演示**设计。

```text
┌──────────────┐       HTTP/JSON       ┌────────────────────┐
│ HarmonyOS 端 │ ────────────────────→ │ Node 后端 :3000     │
│ phone/tablet │                       │ Express + AI 网关   │
└──────┬───────┘                       │ MySQL 快照/账号/用量 │
       │                               └────────────────────┘
       │ HTTP/JSON
       ▼
┌────────────────────┐
│ 流转中转 :3100      │
│ flow-bridge.js      │
└────────────────────┘
```

## 2. 前置软件

### 2.1 鸿蒙端

- DevEco Studio 6.x
- HarmonyOS SDK API 23
- 模拟器或 HarmonyOS NEXT 真机
- `hdc`

本项目已在 HarmonyOS 6.0.2 API 22 模拟器运行验证。

### 2.2 后端

- Node.js 20+；建议使用当前 LTS
- npm 10+
- MySQL 8.x
- Windows、Linux 或 macOS

### 2.3 网络

- 模拟器访问宿主机：`10.0.2.2`
- 真机/平板访问电脑：电脑局域网 IPv4
- 端口：后端 `3000`、流转中转 `3100`

## 3. 获取代码

```powershell
git clone <仓库地址>
cd NexcoreGraph
```

鸿蒙工程目录：

```text
harmonyosapp/NexcoreGraph_harmonyos
```

## 4. 初始化 MySQL

默认数据库名为 `tianshu`。先用管理员账号创建库和独立应用账号：

```sql
CREATE DATABASE IF NOT EXISTS tianshu
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;

CREATE USER IF NOT EXISTS 'nexcore'@'127.0.0.1'
  IDENTIFIED BY '替换为强密码';

GRANT ALL PRIVILEGES ON tianshu.* TO 'nexcore'@'127.0.0.1';
FLUSH PRIVILEGES;
```

业务表由 `initDb()` 在第一次启动时幂等创建，无需手工逐表建表。

## 5. 配置后端

进入：

```powershell
cd harmonyosapp/NexcoreGraph_harmonyos/backend
npm ci
```

在 `backend/.env` 写入部署配置。`.env` 不得提交。

```dotenv
PORT=3000

DB_HOST=127.0.0.1
DB_PORT=3306
DB_USER=nexcore
DB_PASSWORD=替换为强密码
DB_NAME=tianshu

AGNES_BASE_URL=https://api.agnes-ai.cn/v1
AGNES_API_KEY=替换为服务端密钥
AGNES_MODEL=agnes-2.0-flash
AGNES_MODEL_ALT=agnes-3.0-flash
AI_TIMEOUT_MS=30000
AI_RPM=20
AI_VISION_BUDGET_MS=25000
AI_VISION_MAX_TOKENS=900

AUTH_SHOW_CODE=0
AUTH_CODE_TTL_MS=300000
AUTH_CODE_COOLDOWN_MS=60000

MAIL_HOST=smtp.163.com
MAIL_PORT=465
MAIL_USER=发信邮箱
MAIL_PASS=SMTP授权码

FLOW_PORT=3100
```

说明：

- `AUTH_SHOW_CODE=1` 仅用于本地联调；
- 生产环境必须为 `0`；
- 端侧不保存、不打包模型密钥；
- MySQL 默认端口因机器而异，常见为 `3306`，本开发机曾使用 `3307`；
- 不配置 AI Key 时，库存、GraphRAG、本地快答和数字孪生仍可使用，模型类回答返回 503 提示。

## 6. 启动后端与流转中转

### 6.1 Windows 一键启动

```powershell
cd harmonyosapp/NexcoreGraph_harmonyos
powershell -ExecutionPolicy Bypass -File tools/start-lan.ps1
```

脚本会：

1. 启动后端 `3000`；
2. 启动 `flow-bridge.js` `3100`；
3. 打印电脑局域网 IPv4；
4. 打印防火墙放行命令。

如校园网或公共 WiFi 能连上网络但设备互访失败，改用手机热点让电脑和移动设备同连，或换家用路由器。

### 6.2 手动启动

终端 A：

```powershell
cd harmonyosapp/NexcoreGraph_harmonyos/backend
node server.js
```

终端 B：

```powershell
cd harmonyosapp/NexcoreGraph_harmonyos/backend
node flow-bridge.js
```

### 6.3 健康检查

```powershell
Invoke-RestMethod http://127.0.0.1:3000/api/health
Invoke-RestMethod http://127.0.0.1:3100/api/health
```

后端预期：

```json
{"ok":true,"service":"nexcoregraph-backend","mode":"lan-self-hosted","ai":"ready"}
```

流转中转预期：

```json
{"ok":true,"service":"nexcore-flow-bridge","port":3100,"has":true}
```

## 7. 防火墙

管理员 PowerShell 执行一次：

```powershell
New-NetFirewallRule -DisplayName "NexcoreGraph 3000" `
  -Direction Inbound -Protocol TCP -LocalPort 3000 -Action Allow

New-NetFirewallRule -DisplayName "NexcoreGraph 3100" `
  -Direction Inbound -Protocol TCP -LocalPort 3100 -Action Allow
```

Linux：

```bash
sudo ufw allow 3000/tcp
sudo ufw allow 3100/tcp
```

公网部署不要直接暴露 MySQL 端口。

## 9. 模拟器安装与运行

### 9.1 连接设备

```powershell
hdc list targets -v
hdc tconn 127.0.0.1:5555
```

两个模拟器同时运行时，常见端口为 `5555` 和 `5557`。

### 9.2 安装

```powershell
hdc -t 127.0.0.1:5555 install -r `
  entry/build/default/outputs/default/entry-default-unsigned.hap
```

### 9.3 启动

```powershell
hdc -t 127.0.0.1:5555 shell aa start `
  -a EntryAbility -b com.example.myapplication
```

### 9.4 重启端侧应用

```powershell
hdc -t 127.0.0.1:5555 shell aa force-stop com.example.myapplication
hdc -t 127.0.0.1:5555 shell aa start `
  -a EntryAbility -b com.example.myapplication
```

冷启动后若停在锁屏：

```powershell
hdc -t 127.0.0.1:5555 shell uitest uiInput keyEvent Power
hdc -t 127.0.0.1:5555 shell uitest uiInput swipe 660 2500 660 400 700
```

安装后的第一次 `aa start` 可能因包更新事件被系统终止；再执行一次启动即可。

## 10. 模拟器连接后端

模拟器内不能使用宿主机的 `127.0.0.1`。使用：

```text
后端：http://10.0.2.2:3000
流转：http://10.0.2.2:3100
```

端侧「我的 → 服务器连接」支持运行时修改并保存后端地址，无需重新打包。

真机与电脑部署时填写：

```text
http://<电脑局域网IPv4>:3000
```

## 11. 真机安装

1. 真机打开开发者模式与 USB 调试；
2. `hdc list targets` 确认设备；
3. 使用和模拟器相同的 `hdc install -r` 命令；
4. 在「我的 → 服务器连接」填写电脑局域网地址；
5. 两端登录同一账号。

扫码需要设备具备 Scan Kit 能力。系统不支持的设备会自动提示改用拍照/相册。

## 12. 签名与发布

### 12.1 DevEco 自动签名

1. 登录华为账号；
2. `File → Project Structure → Signing Configs`；
3. 勾选自动生成签名；
4. 确认证书、Profile 和包名；
5. 重新执行 Release 构建。

签名文件、密码和 Profile 密码不得进入仓库或 ZIP。

### 12.2 包名

当前包名为：

```text
com.example.myapplication
```

正式上架前应改为团队域名反写，例如：

```text
com.nexcoregraph.app
```

更换包名后必须同步更新：

- AGC 应用/元服务；
- 签名 Profile；
- 自动化测试或脚本中的启动命令；
- 已有用户数据迁移说明。

### 12.3 元服务限制

- 项目为 `atomicService`；
- 当前实测 `NotificationKit` 的本地通知发布接口被平台以 `11706010` 拒绝；
- 桌面提醒使用 Form Kit 服务卡片；
- 若将来需要系统通知，应评估应用包形态并重新验证。

## 13. 公网部署加固

当前后端定位为局域网自建服务。直接暴露公网前必须完成：

1. Nginx/Caddy HTTPS 反向代理；
2. 所有同步、日志、AI 接口校验登录 token 和家庭权限；
3. token 从内存 Map 改为数据库或 JWT；
4. CORS 从 `*` 收紧到允许域名；
5. 登录、验证码和 AI 网关增加 IP/家庭级限流；
6. 数据库使用独立低权限账号，禁止 root；
7. 日志脱敏、轮转和异常上报；
8. 备份、恢复演练和最小权限运维；
9. App 与元服务备案、隐私政策和数据删除流程；
10. 真实 HTTPS 真机回归。

未完成以上项目时，不应将 `3000/3100` 直接暴露到公网。

## 15. 备份与恢复

导出：

```bash
mysqldump -u nexcore -p tianshu > nexcore_$(date +%F).sql
```

恢复：

```bash
mysql -u nexcore -p tianshu < nexcore_2026-11-11.sql
```

`flow-bridge.json` 与 `.rev` 是流转中转快照文件，不是权威业务数据库；清理它们不影响 MySQL 数据。

## 16. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `hdc` 显示 Offline | 模拟器尚未完成启动或端口变化 | 等待、查看 `Emulator -list -details`、`hdc tconn` |
| 启动提示屏幕锁定 | 模拟器冷启动停在锁屏 | `keyEvent Power` 后向上滑动 |
| 首次启动后回桌面 | 新安装包触发应用进程替换 | 再执行一次 `aa start` |
| 后端连不上 | 地址用了 `127.0.0.1` | 模拟器用 `10.0.2.2`，真机用局域网 IP |
| AI 返回 503 | `AGNES_API_KEY` 未配置 | 配置后端环境变量并重启 |
| AI 返回 429 | 达到 `AI_RPM` | 等待或由管理员调整限额 |
| 手机/平板不自动同步 | `3100` 流转中转未启动 | 启动 `flow-bridge.js`，或使用手动“接收流转” |
| 登录验证码看不到 | 未配置邮件/短信 | 本地用 `AUTH_SHOW_CODE=1`；生产配置 SMTP |
| MySQL 连接失败 | 库未创建、端口或账号错误 | 核对 `DB_*`，执行健康检查 |
| 扫码打不开 | 设备不支持 Scan Kit | 使用拍照/相册 |
| 构建找不到 hvigor | 未安装 DevEco 或路径不同 | 传 `-DevEcoHome` 或从 DevEco 构建 |
| HAP 未签名 | `signingConfigs` 为空 | 配置 AGC/DevEco 签名后 Release 构建 |

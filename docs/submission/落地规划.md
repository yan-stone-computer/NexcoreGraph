# 启核图策 · 落地规划

## 1. 上架与发布

### 近期

- 完成正式包名、隐私说明、权限说明和元服务审核材料；
- 使用 DevEco 自动签名生成 Release HAP；
- 优先提交 AppGallery 体验版；
- 以手机和平板为主，2in1 作为第二种核心体验设备。

### 体验版演示路径

1. 扫码或拍照建立四类资源：食品、药品、健身器材、工具；
2. 切换数字孪生的四个资源域；
3. 展示药品不受家庭餐次错误影响；
4. 输入身体数据，按现有器材生成确定性训练计划；
5. 展示工具维护和“不产生虚假日耗”；
6. AI 写操作先出确认卡，确认后执行并可追溯；
7. 手机到平板接续；
8. 展示模型平台切换、脱敏 Key 与 BYOK；
9. 展示 GuardrailBench。

## 2. 用户增长

- 首启三步引导降低空库流失；
- 家庭邀请码带来自然裂变；
- 每类资源提供空白模板和一键示例，降低建库成本；
- BYOK 让已有模型账号的用户零推理成本试用；
- 服务卡片形成每日低频但稳定的回访；
- “本周减少浪费”分享卡适合家庭群传播；
- 针对宿舍、合租和社区场景制作模板库。

## 3. 商业闭环

### 家庭版

- 免费：1 个家庭、基础资源库、本地快答、四域数字孪生、基础训练计划；
- Pro：多成员协作、跨端历史、家庭周报、高级训练与风险分析；
- BYOK：用户自带模型 Key，平台只提供网关、规则、提示模板和评测。

### 组织版

- 面向物业、社区、养老机构和学生公寓；
- 提供公共物资台账、盘点任务、成员角色和运营报表；
- 提供药品余量、器材维护、工具借还和家庭资源健康报告；
- 采用年度订阅、私有部署或项目制服务。

### 成本控制

- 确定性快答不调用模型；
- GraphRAG 减少模型输入的冗余事实；
- 数字孪生、健康度和图谱构建均在端侧完成；
- AI 网关按家庭限流并记录用量；
- 模型平台可热切换，主模型失败后使用备用模型；
- 管理员可配置超时、RPM、视觉预算和模型链。

## 4. 运营机制

- 每日：服务卡片展示 Top 风险；
- 每周：资源健康度与减少浪费摘要；
- 每月：家庭资源报告与建议；
- 每季度：回顾长期浪费模式，更新知识库；
- 用户反馈直接进入固定评测集，防止版本回退。

# 启核图策 · 落地规划

## 1. 上架与发布

### 近期

- 完成正式包名、隐私说明、权限说明和元服务审核材料；
- 使用 DevEco 自动签名生成 Release HAP；
- 优先提交 AppGallery 体验版；
- 以手机和平板为主，2in1 作为第二种核心体验设备。

### 体验版演示路径

1. 扫码或拍照建立三库：冰箱、药盒、工具箱；
2. 查看资源健康度和 7 天风险；
3. 切换“来客 +2”；
4. 让 AI 生成临期处置；
5. 确认执行并撤销；
6. 手机到平板接续；
7. 展示 GuardrailBench。

## 2. 用户增长

- 首启三步引导降低空库流失；
- 家庭邀请码带来自然裂变；
- 服务卡片形成每日低频但稳定的回访；
- “本周减少浪费”分享卡适合家庭群传播；
- 针对宿舍、合租和社区场景制作模板库。

## 3. 商业闭环

### 家庭版

- 免费：1 个家庭、基础资源库、AI 基础额度；
- Pro：多家庭、更多成员、数字孪生历史、家庭周报。

### 组织版

- 面向物业、社区、养老机构和学生公寓；
- 提供公共物资台账、盘点任务、成员角色和运营报表；
- 采用年度订阅或项目制部署。

### 成本控制

- 确定性快答不调用模型；
- GraphRAG 减少模型输入的冗余事实；
- 数字孪生、健康度和图谱构建均在端侧完成；
- AI 网关按家庭限流并记录用量。

## 4. 运营机制

- 每日：服务卡片展示 Top 风险；
- 每周：资源健康度与减少浪费摘要；
- 每月：家庭资源报告与建议；
- 每季度：回顾长期浪费模式，更新知识库；
- 用户反馈直接进入固定评测集，防止版本回退。

## 5. 后续迭代

### 30 天

- 签名发布；
- 真机多设备验收；
- 补充真实消耗日志；
- 接入家庭邀请与周报。

### 90 天

- 验证应用包形态的系统通知；
- 验证 Intents Kit 与小艺建议；
- 增强药品、保修期和公共物资模板；
- 引入更细粒度的角色权限。

### 180 天

- 社区公共资源台账；
- 多家庭/组织管理员；
- 运营数据看板；
- 与本地生活服务和回收服务合作。

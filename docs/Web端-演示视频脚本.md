## 2. 逐条精确操作（照着点）

### 第 3 段：拍照入库
1. 左侧导航 →「首页看板」。
2. 页面上方按钮 →「拍照入库」（打开浮层）。
3. 把桌面照片拖进取景框，或点「选择文件」。
4. **不要急着点**，让识别结果停留 2 秒，鼠标依次划过：名称 / 数量 / 存放位置 / 保质期 / 价格。
5. 点「确认入库」。若有多条，确认「合并同名」后的件数。

### 第 5 段：一句话改库存
1. 右下角 AI 浮球（或「AI 工作台」底部输入框）。
2. 输入：`鸡蛋还剩 5 个`，回车。
3. 出现「库存调整预览」卡片 → 点「确认生效」。
4. 左侧「资源库」→ 冰箱 → 看鸡蛋数量已变成 5。

### 第 6 段：方案与证据
1. AI 输入框输入：`今晚吃什么`，回车。
2. 回答下方出现方案卡；鼠标停在「证据：…」那行小字上。

### 第 7 段：核销与撤销
1. 打开「方案」列表 → 选刚生成的方案。
2. 勾选用掉的食材 →「执行」。
3. 回「资源库」看数量减少 → 设置 →「撤销最近操作」恢复。

### 第 8 段：资源图谱
1. 左侧「资源图谱」。
2. 点任意物品节点 → 右侧/下方出现邻域与路径证据。
3. 若有「multi-hop」入口，切一次给镜头看路径链。

### 第 9 段：活同步
1. 窗口 A：右上角头像 → 设置 → 往下滚到「多端活同步 · 跨设备流转」→ 状态应为「已连接 · 自动同步中」。
2. 窗口 B（同账号）停在首页。
3. 窗口 A 在资源库里把某件物品数量 +1；**窗口 B 不做任何操作**，2 秒内数字自动变。
4. 顺手点一次「发送流转」，窗口 B 点「接收流转」，提示"已接收…"。

### 第 10 段：收尾
1. 点左侧「首页看板」。
2. 画面停在看板 2 秒再结束录制。

## 3. 录制要点

- **一段只做一件事**，动作完成后停 1 秒再切下一步，观众才跟得上。
- **识别/同步的等待不要剪**：那 2~3 秒就是"真 AI、真同步"的证据。
- **口播数字必须和画面一致**：临期件数、识别件数、同步耗时，先说画面里的数。
- 如果某次识别返回 0 项，别重录：正好讲"它不会硬凑物品"，这是加分点。
- 每段先点完再开口，避免边点边说导致漏说。

## 4. 被问到时的备用话术

| 问题 | 回答 |
|---|---|
| AI 是不是只调了个接口？ | 三件事：GraphRAG 证据装配（回答带路径与来源）、工具协议（写操作先确认）、意图路由（问候/位置/数量/保质期 0 次模型调用）。 |
| 数据放哪、隐私怎么保证？ | 局域网自建：后端在用户电脑上，数据不出局域网；聊天正文与图片二进制不随流转同步；密钥放本机 `.env`，不进仓库。 |
| 多端怎么做的？ | 同一份快照 DTO + 版本号过滤 + 按 id 原地合并；2 秒轮询，实测两台设备间自动落地。 |
| 为什么 Web 不用框架？ | 这一版刻意免构建，双击即可运行；模块边界按状态层/视图层/AI 编排层拆开，迁 Vue 3 是 1:1 映射。 |
| 和记账 App 的区别？ | 记账是"人填表、AI 聊天"；这里是"AI 出结构、人只补缺"，且库存直接驱动方案、采购与协作。 |

## 5. 避坑

1. **登录页一直显示"未找到本机后端"**：后端没起，或起的是旧进程（没有 CORS）。重跑
   `tools\start-lan.ps1`；确认 `:3000/api/health` 能通。
2. **拍照入库没反应**：浏览器要用 `http://127.0.0.1:8090`，不要用 `file://` 双击打开（摄像头与
   `.env` 读取都受限）。
3. **活同步不生效**：确认 `:3100/api/health` 能通（流转中转是独立进程）。
4. **口播超时**：先删第 8 段（资源图谱）或第 7 段（撤销演示），保留拍照入库、一句话改库存、多端活同步三段。

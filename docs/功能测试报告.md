## 三、本轮修掉的真实缺陷（都是实测发现的）

| 缺陷 | 现象 | 修法 |
|---|---|---|
| 空牌桌崩溃 | 点"工作台"直接闪退（jscrash：Cannot read property color of undefined @ WorkbenchView:242） | 下标存在才画座位，否则画空位；补"上桌"入口 |
| 登录按钮被键盘盖住 | 输验证码时软键盘顶起半屏，"登录"按钮完全不可见（视觉读屏确认） | 登录页改可滚动 |
| 建库按钮被键盘盖住 | "新建资源库"里键盘挡住"创建库"，弹层还滚不动 → 根本建不了库 | 输入框回车即提交（`Field.submit`），按钮与回车共用一份实现 |
| 工作台不重绘 | Workbench 是普通类（要进同步 DTO），内部改动界面不刷新 | `cloneForRender()` + `store.touch()` |
| 成员数显示 undefined | "undefined 位成员"（后端 member_count 与端侧 memberCount 命名不一致） | 两种字段都兼容，老缓存兜底为 1 |
| 读图卡死 | 相册授权 URI 直接丢给 createImageSource 不回调 | 改 fd 打开 + 12s 硬超时 |

## 四、本轮未覆盖（需要额外条件）

| 项 | 原因 | 建议验证方式 |
|---|---|---|
| 服务卡片（4 张） | 桌面卡片需手动添加到桌面，命令行无法完成 | 长按桌面 → 服务卡片 → 添加"启核图策"卡片，看库存/临期是否随入库变化 |
| 跨设备自由流转 | 需要第二台设备（平板/手机）同账号同 WiFi | 先起平板模拟器，两端登录同一账号，一端改数据看另一端 2 秒内自动跟上 |
| 真机拍照入库 | 模拟器无相机（点拍照会提示"没有可用相机，请用从相册选择"） | 真机点拍照 → 拍照 → 识别 → 补缺 → 确认入库 |
| 平板/2in1 布局 | 需启动 MatePad Pro 11 模拟器 | 用平板形态复核侧边栏通高 + 首页三列 + 看板一行三卡 |
| 手表端 | 已在设置中按用户要求不做 |

## 五、已知小问题（不影响主流程）

1. **multi-hop 图谱证据在数据量小时为空**：端侧对"做饭/采购"类意图固定请求 multi-hop，但库里只有 1 件物品时返回 0 条证据（后端日志 `mode=multi-hop lines=0`）。建议端侧在证据为空时自动降级到 local 模式，或在提示里说明"证据不足"。
2. 首页空态文案写"你的库还是空的"，实际可能是"有库但没物品"；建议按 `libraries.length === 0` 与 `items === 0` 分开措辞。

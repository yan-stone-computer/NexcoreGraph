## 二、发现并修复的问题

### 高优先级：静态服务可能暴露 `.env`

复核日志发现旧启动方式 `python -m http.server` 会响应：

```text
GET /.env 200
```

虽然 `.env` 已被 `.gitignore` 排除，但部署到公网后仍可能泄露模型密钥。

修复措施：

1. 浏览器 AI 客户端删除 dotenv 下载与解析逻辑。
2. 新增 `tools/serve_web.py`，拒绝点文件、目录列表和路径穿越。
3. Web 启动脚本统一改用安全静态服务器。
4. 新增 `tests/security.test.js` 防止回归。

修复后实测：

| 请求 | 结果 |
|---|---|
| `/.env` | 404 |
| `/.env.example` | 404 |
| `/..%2f..%2f.env` | 404 |
| `/assets/` 目录列表 | 404 |
| `/` | 200 |

页面运行日志中不再出现浏览器主动请求 `.env`。

局域网模式另行使用 `--bind 0.0.0.0 --port 8083` 实测：

- `http://10.51.102.251:8083/index.html`：200
- `http://10.51.102.251:8083/.env`：404

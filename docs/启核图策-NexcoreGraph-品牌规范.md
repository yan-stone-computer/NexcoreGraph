# 启核图策 NexcoreGraph · 品牌规范 v3

> 定稿方案：**E3**（取景框 + 折叠地图 + 规划路线 + 目标旗 + 官方徽标）。
> 官方圆形徽标（绿→青→蓝渐变 + 顶部嫩芽 + 白色 N 与弧线）保留为画面中的元素之一，不再是主体。

## 1. 图标构成与意向

| 意向 | 图形语言 | 位置 |
|---|---|---|
| 识别 | 大号四角取景框；框内左上角放官方徽标，代表"被识别到的核心物品" | 外框 + 左上 |
| 地图 | 折面分区的地图轮廓 + 极淡网格 | 框内主体 |
| 规划 | 带节点的路线 + 终点小旗 | 贯穿框内 |
| 策 | 路线走向与节点取舍形成的路径选择 | 中部 |

## 4. 使用规则

- 应用图标保持满幅深底，不要自行加圆角或描边；小尺寸（≤32px）用 `icon-32` 或单色版。
- 组合标内图标高度 = 中文字高的约 3.3 倍；中文与英文左对齐，英文全大写、字距 0.08em。
- 图标四周留白 ≥ 图标高度的 10%；不要把图标压在杂乱图片上。
- 不改配色、不改渐变方向、不加投影与描边；不把赛事标识拼进图标。

## 5. 官方徽标的单独使用场景（与 E3 图标并存）

官方圆形徽标（`nexcore-graph-logomark.png` / `nexcore-graph-logo-{256,512,1024}.png`）在小尺寸与品牌位单独使用，因为它是单一主体、在 16–32px 下比 E3 图标清晰得多：

| 场景 | 用哪个 | 位置 |
|---|---|---|
| 浏览器标签（favicon / favicon.ico） | **官方徽标**（透明底，方形版，16/32/48/64/128/256） | `web/NexcoreGraph_web/assets/img/favicon.ico`、`favicon-32.png` |
| 页面内品牌位（侧栏 40px、登录页 96px） | **官方徽标**（方形版 256，容器用 `object-fit: contain`） | `web/NexcoreGraph_web/assets/img/logo.png` |
| iOS 主屏 / Android PWA 图标 | **官方徽标 + 深底圆角板** | `apple-touch-icon-180.png`、`web-app-manifest-{192,512}.png` |
| 应用图标（鸿蒙 / 小程序 / 商店） | **E3 图标**（`icon-*`） | 各端 `media/`、`src/assets/logo.png`、`docs/brand/` |
| 组合标、路演物料 | E3 图标（圆角版） + 文字标 | `lockup-*` |

> 判定原则：**正方形小尺寸（≤32px）与浏览器/主屏图标用官方徽标；大尺寸应用图标与组合标用 E3。**

## 6. 应用内主题映射（2026-09-15 新增，默认主题跟随徽标）

徽标配色为 绿 `#46B14C` → 青 `#2FD4B2` → 蓝 `#0CA8D6`（深底 `#13172B`）。自本版起，
应用默认主题**直接采用徽标色系**（启核色板 · 深色），并保留早期品牌橙作为可切换的"经典"色板。

> **配色来源：直接取自徽标像素，不引用文档转述值。** 取样脚本：读 `nexcore-graph-logomark.png`（母版 308×430），
> 在**不透明区域按高度百分比**逐行取"饱和度 > 0.25 且不透明"像素的均值，得下表阶梯（可复现）。

| 高度 | 实测色值 | 令牌用途 |
|---|---|---|
| 2% | `#ABE05A` 嫩芽黄绿 | `tone-lime`（嫩芽/高光） |
| 15% | `#8CD35B` 绿 | `success`、深色态 `primary-ink` |
| **30%** | **`#57D794` 绿青** | **`primary` 主操作（填充，明暗同值）** |
| 45% | `#3DD0AE` 过渡青 | `accent`（AI/强调） |
| 60% | `#26C2BC` 科技青 | `tone-teal` |
| 75% | `#1FB5CC` 蓝青 | —（渐变中段） |
| 90% | `#27ADD7` 信号蓝 | `tone-indigo`（数据/图表） |
| 99% | `#1492CB` 深蓝 | 渐变尾段 |
| — | `#FEFEFE` 徽标白 | 深底正文/圆内图形 |
| — | `#13172B` 深海军蓝 | 应用图标底、深色态 surface |

**三色分工**：**绿 = 主操作/生长** · **青 = AI/强调** · **蓝 = 数据/图表**。

**派生色（仅为对比度，不改品牌观感）**

| 令牌 | 值 | 说明 |
|---|---|---|
| `primary-ink` | 浅色 `#2E8F63` / 深色 `#8CD35B` | 浅底/深底上的**文字与图标**用；填充一律用徽标原值 |
| `primary-hover` | 浅色 `#3DD0AE` / 深色 `#6ADFA3` | 悬停态 |
| `*-container` | 同色 16–18% 透明度 | 卡底、soft 按钮 |
| 经典色板 | `#FF8833` / `#E8701E` | 早期品牌橙，保留以兼容既有物料 |

| 其他令牌 | 启核（默认） | 经典 |
|---|---|---|
| `surface` 底色 | 冷白 `#F5F9FB`（浅，默认）/ 深海军蓝 `#13172B`（深） | 暖白 `#FBF7F2` / `#13172B` |
| `text-primary` | `#0E1424` / `#F2F7FB` | `#221A12` / `#F2F4FA` |
| 品牌渐变 | 绿→青→蓝 135°（`#8CD35B → #3DD0AE → #27ADD7` 低透明度） | — |

落地规则：

1. **唯一来源**：`entry/src/main/ets/common/Tokens.ets`；页面禁止写死颜色（沿用既有禁令）。
2. **默认值**：启核色板 + **浅色**（冷白底 `#F5F9FB` + 启核绿主色）；深色可手动切换。切换入口在「设置 → 外观」，另提供"恢复品牌默认主题"。
3. **其他端同步**：Web / 小程序 / 安卓 / Qt 接入时复用同一令牌映射（Web 可先映射为 CSS 变量）。
4. **验收口径**：整屏截图像素统计——启核主题应无经典橙像素（见补充方案附录 D.4/D.6 实测数据）；主按钮取样必须落在启核绿家族（深色 `#46B14C` / 浅色 `#2F8F3A`）。
6. **禁忌**：不得把"信号蓝"当作主操作色使用——蓝只用于数据表达（图表、环形图、tone-indigo）与渐变尾段；**填充色不得改用派生墨绿**（`primary-ink` 只用于文字/图标）。
5. **AI 头像**：使用官方徽标 `nexcore-graph-logomark.png`（应用内为 `entry/.../media/ai_avatar.png`），不再用图标字体占位。

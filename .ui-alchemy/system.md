# 启核图策 · UI 方向与系统决定（ui-alchemy）

> 建立：2026-09-15｜适用：鸿蒙端（ArkUI）；Web / 小程序 / 安卓 / Qt 复制时沿用同一方向与令牌。

## 1. Design read（一句话）

**给家庭用户与评委用的 HarmonyOS 产品界面（Operate 型）**：要像系统原生工具一样安静、密集、可信，而不是像一块"AI 生成的应用"。

- 模式：Operate（完成任务）＞ Persuade。扫描性、层级、状态一致性优先于表达欲。
- 平台语境：HarmonyOS = 卡片式分层、大圆角、半透明材质。**卡片是平台语言，但只在需要"分层"时用**，不作为默认容器。
- 配色来源：官方徽标像素（`#57D794` 绿 / `#3DD0AE` 青 / `#27ADD7` 蓝），见品牌规范 §6。

## 2. 拨盘（dials）

| 拨盘 | 取值 | 依据 |
|---|---|---|
| `DESIGN_VARIANCE` | 4 | 工具型界面，结构可预期；不追求不对称艺术排版 |
| `MOTION_INTENSITY` | 3 | 只保留状态切换与 toast；不做入场动画堆叠 |
| `VISUAL_DENSITY` | 5 | 数据可扫描：8pt 网格、细线分隔、等宽数字 |

## 3. 明令禁止（craft floor 对齐，本项目硬约束）

1. **渐变铺底**：品牌三段渐变不得作为容器背景（历史问题：AI 摘要条曾铺绿→青→蓝渐变）。渐变只允许出现在品牌物料与徽标本身。
2. **同尺寸卡片堆叠**：一屏不得连续出现 3 张以上等尺寸圆角卡作为页面结构。
3. **hero-metric 模板**：大数字 + 小标签的三等分卡（曾出现于"价值指标"）禁止；改为事实行。
4. **卡片套卡片**：卡片内不得再放卡片；卡片内用细线分隔行。
5. **emoji 当图标**：图标一律取自 `common/Icons.ets` 的自绘线条图标；数据里自带的 emoji 仅作为物品标识。
6. **彩色左边框 / 硬投影 / 玻璃模糊装饰**：不使用。

## 4. 版式规则

- **每屏一个焦点**：AI 工作台的焦点是「今天要处理」，其余内容退为背景层（label-value 行）。
- **层级只用三档**：`strong` 600 主色 / `regular` 500 次色 / `muted` 400 弱色；同一字号也能分层。
- **间距走 8pt 网格**：4/8/12/16/24/32，标题上方留白 > 下方。
- **数字等宽**：所有数值（数量、百分比、耗时、版本）用 `fontFeature('tnum')`。
- **升效声明一次**：容器要么 1px 描边，要么阴影，不同时用。
- **文案**：控件名即动作（"执行"/"确认"，不用"提交"）；空态邀请动作，不写感想。

### 5.1 服务卡片改版（桌面最好的一张脸）

卡片是用户在**桌面**唯一能看到的界面，所以它承担品牌识别；但四张卡各带一套 logo + 名称属于重复装饰，已删除，只保留在快捷入口卡上。

| 卡片 | 改版前 | 改版后 |
|---|---|---|
| 快捷入口 `FuncCard` | 品牌头 + 2×2 入口（**旧品牌橙**渐变填充 + 橙描边） | 品牌头（唯一保留）+ 2×2 入口改为**中性描边方块**（`rgba(255,255,255,.06)` + 1px 描边），无渐变无彩影 |
| 库存总览 `StockCard` | 品牌头 + "N 件 · M 库" + **两个胶囊按钮**（拍照入库 / 查看库存） | 去掉品牌头与胶囊：`库存` 标签 → **30vp 等宽大数字 `N` 件** → `M 个库` → 底部状态点（临期=琥珀 / 健康=启核绿）。整卡可点 |
| 临期提醒 `ExpiryCard` | 品牌头 + 24vp 数字 + 两行列表 + `查看预警中心 →` | 去掉品牌头；`临期` 标签 → **30vp 等宽数字**（有临期=琥珀，无=启核绿）→ 明细最多两条 → `查看全部` 文本链接 |
| 打开库存 `LibCard` | 74vp **彩色渐变图标块 + 橙色阴影**（绿块配橙影） | 图标退入 **38vp 中性描边方块**（去掉彩色光晕与偏移彩影）；`N 件` 用 26vp 等宽数字 + `M 个库` |

统一约束：底座低反差竖向渐变（`#171C33 → #13172B`，属平台卡片语言，非彩色装饰）；正文三档（`#EDF1F9` / `#C3CDE6` / `#8E9AB8`）；唯一强调色 `#57D794`；状态色仅表状态；数字一律 `tnum`；圆角 12–14；内边距 12–13。

技术注意：ArkTS 服务卡片的多文件**顶层常量共享作用域**，4 个卡片文件必须给常量加前缀（本项目用 `FC_ / SC_ / EC_ / LC_`），否则报 `Cannot redeclare block-scoped variable`。

### 5.2 卡片配色与软件对齐（第二轮修正）

首发版卡片是**深色**（`colorMode: dark`）而软件默认是浅色，属于硬性不一致；另一版又把品牌色退成中性灰，识别度归零。现改为：

1. **颜色走主题资源**：新增 `app.color.card_*` 令牌（`resources/base` 浅色 + `resources/dark` 深色两套），卡片不写死十六进制；
2. **`form_config.json` 的 `colorMode` 由 `dark` 改为 `auto`**，随系统明暗切换，与软件默认浅色一致；
3. **每张卡都带官方徽标**：头部统一为「徽标 14vp + 标签」，语义图标（冰箱/时钟）留在右侧；`LibCard` 去掉多余方块，改为徽标 + 标签 + 大数字；
4. **签名元素**：仅保留顶部 3vp 徽标三段渐变条（`#8CD35B → #3DD0AE → #27ADD7`），其余全部素色；
5. 结构统一：渐变条 → 头部（logo + 标签 + 语义图标）→ **30vp 等宽大数字** + 单位 → 状态行（临期=琥珀 / 健康=墨绿）/ 明细行 → `查看全部` 文本链接。

## 6. 验证方式（无视觉环境下的可测代理指标）

- 布局树：必需文案与分区存在；无内容区同尺寸三等分组；无悬浮球遮挡（遮挡文本元素数 = 0）。
- 像素：内容区高饱和像素占比 ≤1%（克制度）；底色为纯 surface（无渐变带）。
- 像素：主操作填充与徽标实测值 ΔRGB ≤ 2。
